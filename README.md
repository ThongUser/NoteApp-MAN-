# NoteApp-MAN

## Yêu cầu hệ thống

- Node.js phiên bản 16 trở lên.
- npm (được cài cùng Node.js).

## Chạy Backend

Mở terminal tại thư mục gốc của dự án và chạy:

```bash
cd backend
npm install
node server.js
```

Backend chạy tại: http://localhost:5000

## Chạy Frontend

Mở một terminal khác tại thư mục gốc của dự án và chạy:

```bash
cd frontend
npm install
npm run dev
```

Frontend chạy tại: http://localhost:5173

## Lưu ý

Hệ thống sử dụng các file JSON để lưu dữ liệu tại thư mục `backend/data/`. Vui lòng không xóa thư mục này trong quá trình sử dụng.
